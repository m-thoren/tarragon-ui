# @tarragon-ui/styles

Simple and opinionated CSS for Tarragon UI, including component styles and utility classes.

## Installation

```sh
npm install @tarragon-ui/styles
```

Or use pnpm or yarn:

```sh
pnpm add @tarragon-ui/styles
yarn add @tarragon-ui/styles
```

Import the package once from your application entry point:

```js
import '@tarragon-ui/styles'
```

This package includes the base styling for Tarragon UI components and layout utilities. Pair it with the JavaScript package for interactive behavior:

```js
import '@tarragon-ui/styles'
import '@tarragon-ui/js'
```

The CSS package is intentionally lightweight and designed to work with the documented HTML structure and state attributes used by the components.
